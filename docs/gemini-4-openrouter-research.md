# Gemini 4: existence and OpenRouter availability

Research date: 2026-10-05. **Direct answer: Gemini 4 exists, but it is not currently usable through OpenRouter based on OpenRouter's live model catalog checked on this date.** Google's announcement identifies the model as **Gemini 4 Argon**; it describes a restricted phased rollout and says broader access—including paid API customers—is still to come. OpenRouter's model-search API returned no results for `gemini-4`, so there is no verified OpenRouter model slug to use. These are separate facts: Google's model announcement does not itself establish that OpenRouter lists or serves the model. [Google announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/) · [OpenRouter live catalog search](https://openrouter.ai/api/v1/models?q=gemini-4)

## Findings

- **Existence: yes.** Google announced **Gemini 4 Argon** on September 30, 2026, calling it a new frontier model. The announcement says it is rolling out first to trusted cyber defenders through Google's Fairwind Program. [Google, “Gemini 4 Argon: our next era of frontier intelligence”](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/) (published 2026-09-30).
- **Public Google API access: not established yet.** Google says it is gradually expanding access, gathering early-tester feedback and strengthening safeguards before releasing Argon to developers, enterprises and consumers; it says that broader release will start with paid API customers and Google AI Ultra subscribers. Thus, the announcement is not evidence that a public API endpoint is already generally available on 2026-10-05. [Google announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/).
- **Google API model ID: none verified.** Google's Gemini API model directory, last updated October 1, 2026, lists Gemini 3 and Gemini 2.5 families and their endpoint IDs, but no Gemini 4 model or endpoint. The `gemini-4-argon` string in Google's announcement title is a product name, not a documented API model ID. Do not infer an API endpoint slug from it. [Google Gemini API model directory](https://ai.google.dev/gemini-api/docs/models) (last updated 2026-10-01).
- **OpenRouter listing/access: no, as checked.** OpenRouter documents `GET /models` as the endpoint for listing its available models, with `q` supporting a free-text search by model name or slug. Its live query `https://openrouter.ai/api/v1/models?q=gemini-4` returned `{"data":[],"total_count":0,...}` on the research date. A direct request for the guessed endpoint detail path `https://openrouter.ai/api/v1/models/google/gemini-4-argon/endpoints` returned HTTP 404. This supports “not listed/not verifiably routable through OpenRouter at check time,” not “Google has no Gemini 4.” [OpenRouter model-list API documentation](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties) · [live catalog query](https://openrouter.ai/api/v1/models?q=gemini-4) · [guessed endpoint detail path](https://openrouter.ai/api/v1/models/google/gemini-4-argon/endpoints).

## Practical takeaway

Do not use or publish a guessed OpenRouter model slug such as `google/gemini-4-argon`; it is not present in the checked catalog. Recheck OpenRouter's live [model catalog](https://openrouter.ai/models) or `GET https://openrouter.ai/api/v1/models?q=gemini-4` after Google broadens API access. Availability on OpenRouter would require OpenRouter to list and serve a model; Google's announcement alone does not establish that integration. [OpenRouter model-list API documentation](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties).
